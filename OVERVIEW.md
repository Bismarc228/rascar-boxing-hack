Overview
Boxing Action Recognition Challenge
В этом соревновании участникам предстоит разработать алгоритм для автоматического анализа боксерских поединков по видео.

На вход подаются видеозаписи раундов, снятые одной статичной камерой из-за ринга. Нужно найти все моменты ударов и определить, какой спортсмен нанес каждый удар: red или blue.

Сабмит представляет собой таблицу событий: одна строка — один предсказанный удар. Для каждого события нужно указать кадр удара, атакующего спортсмена и дополнительные атрибуты удара.

Ключевая часть задачи — корректно найти сам момент удара и определить бойца, который его нанес. Дополнительные характеристики удара позволяют улучшить итоговое качество решения.


Task Description
Датасет содержит видеозаписи любительских боксерских турниров и тренировок. Видео нарезаны по раундам. Все записи сняты одной статичной камерой, расположенной за рингом и покрывающей всю площадку.

В кадре обычно видны оба спортсмена, рефери и часть окружения. Иногда могут быть заметны зрители или другие визуальные помехи.

Спортсмены обозначаются как red и blue. Это не имена бойцов, а стороны в рамках конкретного видео.

Экипировка и цвет спортсменов
Цвет спортсмена определяется по экипировке: шортам, майке, перчаткам и, если присутствует, шлему.

На турнирных видео экипировка обычно хорошо соответствует цвету спортсмена: красный спортсмен выступает в красной форме, синий — в синей.

На тренировочных видео ситуация сложнее: часть экипировки может иметь нейтральный цвет, например черный. Поэтому при построении решения важно учитывать не только цвет отдельных элементов формы, но и устойчивый трек спортсмена, его положение в кадре и поведение на протяжении раунда.

Что нужно сделать
Модель должна проанализировать test-видео и вернуть список найденных ударов.

Для каждого удара нужно определить:

кадр, на котором произошел удар;
спортсмена, который нанес удар;
тип удара;
бьющую руку;
цель удара;
результат удара;
был ли удар чистым или в нем присутствовал шум/заслонение.
Кадры нумеруются с нуля внутри каждого mp4-файла, как в train/punches.csv.

Почему задача сложная
Задача требует анализа движения во времени, а не только классификации отдельных кадров. Модели нужно отличать реальный момент удара от замаха, подготовки, перемещения, защитного движения или клинча.

Основные сложности:

быстрые движения рук и корпуса;
перекрытия спортсменов друг другом;
присутствие рефери в кадре;
различия между турнирными и тренировочными видео;
неоднозначные ситуации с попаданием, блоком и промахом;
возможные заслонения и визуальный шум;
необходимость не генерировать лишние удары на спокойных фрагментах.
Участникам рекомендуется использовать временной контекст: последовательности кадров, keypoints, треки спортсменов, движение рук, дистанцию между бойцами и динамику корпуса.

Baseline
Организаторы предоставят baseline-код, который можно использовать как стартовую точку.

Baseline включает детекцию людей, pose estimation с помощью YOLO-pose, трекинг бойцов, разделение спортсменов на red и blue, а также выделение рефери и зрителей в отдельные категории.

На основе baseline можно строить собственные решения: добавлять классификацию действий по последовательностям keypoints, использовать video models, temporal models, постобработку событий или улучшенные алгоритмы трекинга.

Evaluation
Метрика
Сабмиты оцениваются macro-average по видео. Для каждого test-клипа предсказанные удары сопоставляются с разметкой по времени (алгоритм Венгера, окно ±1,0 с). В скор входят: момент (50%), боец (20%), тип удара (10%), результат (8%), рука и цель (по 6%), минус штраф за лишние предсказания (FP). В ground truth учитываются только удары с clear=true. Строки сабмита с clear=false не матчатся и не считаются FP. Скор в [0, 1], выше — лучше.

Submission File
Формат — как в sample_submission.csv на вкладке Data.

Каждая строка — одно предсказанное событие удара на test-клипе. Нужно то же число строк, что в шаблоне (колонка id от 1 до n). Порядок строк на оценку не влияет.

Обязательные колонки:

id,video_id,agn_index,video_key,frame,fighter,punch_type,hand,target,effectiveness,clear
1,АГН-37,37,agn_037,2315,blue,hook,right,head,miss,true
2,АГН-37,37,agn_037,2339,red,jab,left,body,blocked,true
3,АГН-38,38,agn_038,1200,red,cross,left,head,landed,true
Колонка	Тип	Описание
id	int	Номер строки 1…n (как в sample)
video_id	string	Test-клип: АГН-37 … АГН-64 (9 видео)
agn_index	int	Числовой id клипа (см. test/videos.csv; для метрики не используется)
video_key	string	ASCII-id, напр. agn_037 (для метрики не используется)
frame	int ≥ 0	Номер кадра в этом mp4, с нуля
fighter	string	red или blue (угол камеры)
punch_type	string	jab, hook, cross, uppercut
hand	string	left или right
target	string	head или body
effectiveness	string	landed, blocked или miss
clear	string	см. ниже
Метрика
Скор за одно видео
final_score = 0,50 · score_time
            + 0,20 · score_fighter
            + 0,10 · score_punch_type
            + 0,08 · score_effectiveness
            + 0,06 · score_hand
            + 0,06 · score_target
            − fp_penalty
Результат зажимается в [0, 1]. Лидерборд — macro-average по всем test-видео, у которых есть GT с clear=true.

Шаг 1 — Сопоставление
Предсказания сопоставляются с GT алгоритмом Венгера по временному расстоянию.

Окно: ±1,0 с (|t_gt − t_pred| ≤ 1,0, где t = frame / 30).
При равном времени у кандидатов приоритет у пары с тем же fighter.
TP — GT-удар с предсказанием в окне (один-к-одному).
FN — GT-удар без пары.
FP — предсказание без GT в окне.
Шаг 2 — Ошибка по времени (для каждого TP)
time_error = min(1,0, |t_gt − t_pred| / 0,5)
Примеры: 0 с → 0,0; 0,25 с → 0,5; ≥ 0,5 с → 1,0. Если time_error = 1,0, ошибки атрибутов для этой пары считаются максимальными (для punch_type и effectiveness — с весом класса GT).

Шаг 3 — Ошибки по атрибутам
Для TP с time_error < 1,0: 0, если значение совпало с GT, иначе штраф 1 (для punch_type и effectiveness при промахе — вес класса GT, см. шаг 4).

Для FN: максимальный штраф по всем компонентам (для взвешенных полей — с весом класса GT).

Сравниваются: fighter, punch_type, hand, target, effectiveness.

Шаг 4 — Компонентные оценки
Для time, fighter, hand, target:

score_X = 1 − (сумма ошибок по X) / N_gt
Для punch_type и effectiveness — balanced accuracy с весами обратной частоты по классам GT в этом соревновании:

w_c = N_total / (N_classes × N_c)
Знаменатель — сумма w_c по всем GT-ударам видео. Редкие классы (например uppercut, blocked) дают больший вклад при угадывании.

Внутри метрики effectiveness приводится к hit / block / miss (landed → hit, blocked → block, miss → miss).

Шаг 5 — Штраф за FP
fp_penalty = N_fp / (N_gt + N_fp)
FP / GT	Штраф
0	0,00
0,5×	0,33
1×	0,50
4× (у лимита 5×)	0,80
